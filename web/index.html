Download for Linux amd64 GitHub

Clean. Frameless. Distraction‑free.

Everything lives on one screen — chats, model switching and provider settings.

Built to disappear.

Zero clutter between you and the model.

Any OpenAI-compatible provider

Groq, OpenRouter, LM Studio or your own endpoint — switching is one pill click away.

Searchable model picker

Your provider’s whole /models catalog in one popup, filtered as you type.

Conversation history

Chats live in a local SQLite database with a rolling 15-message context window.

Encrypted by default

API keys are sealed with AES-256-GCM and stored on your disk — never in plain text.

Frameless UI

A soft dark window that gets out of your way and lets the model speak.

Go + Electron

A tiny Go binary drives the whole app, so startup is instant and the bundle is small.

Kairo Cares About Your Privacy

Your keys never leave your machine. Your chats never leave your disk. There is no cloud in Kairo — and no telemetry.

  • AES-256-GCM encrypted keys
  • Local SQLite storage
  • Zero telemetry
